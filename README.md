
Node author or admin condition
==============================

Description
-----------

Node author or admin condition provides a ready-to-use block visibility condition to show any block only for the node's author and administrators.


Installation
------------

- Install this module using the official Backdrop CMS instructions at
  https://docs.backdropcms.org/documentation/extend-with-modules.


Usage
-----

1. Navigate to your Layout configuration (Structure > Layouts) where your block is placed. 
2. Click Configure on the block you want to restrict.
3. Under the Visibility conditions section, click "Add condition".  
4. Select "Node author is current user (or admin)" from the dropdown list. 
5. Click "Update Block", then "Save Layout".
